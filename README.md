# 🔐 Link Vault

A clean, editorial-style bookmark manager. Save, tag, search, and organize every link you care about.

## ✨ Features
- **Save any URL** — One-click save with title, tags, and personal notes
- **Tag system** — Organize links into custom tags, filter with one click
- **Tag cloud** — Visual overview of all your tags in the sidebar
- **Search** — Instantly filter by title, URL, or tag
- **Sort modes** — Newest, A–Z, or Oldest
- **Color-coded cards** — Each link gets a unique accent color
- **Favicon fetching** — Auto-fetches site icons for visual recognition
- **Copy URL button** — One-click copy to clipboard
- **Link counter** — See how many links and tags you have at a glance
- **100% local** — All data stored in localStorage

## 🚀 Live Demo
Enable GitHub Pages: **Settings → Pages → Branch: master → Save**

Then visit: `https://DAPHOENIX2000.github.io/link-vault`

## 🛠 Tech Stack
- Pure HTML, CSS, JavaScript
- Google Fonts: DM Sans, DM Serif Display
- Google Favicon API for site icons

## 🎯 How to Use
1. Paste a URL in the top search bar
2. Click **+ Save Link** → fill in title, tags, and notes
3. Browse by tag in the sidebar
4. Search across all your saved links
